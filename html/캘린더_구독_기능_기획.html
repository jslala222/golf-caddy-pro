1 기능 개요 & 동작 원리

캐디 매니저 Pro가 구독 URL 1개를 생성해주면,
사용자가 스마트폰 캘린더 앱에 URL을 한 번 등록하는 것만으로
이후 일정 변경이 자동으로 폰 캘린더에 반영됩니다.

💡
외부 유료 API 없음 — Google OAuth 심사 없음 — iOS/Android/삼성 모두 지원
완전 무료로 기존 Vercel + Supabase 위에서 동작합니다.
구분 설명
구독 URL 형태 https://caddy-pink.vercel.app/api/calendar/{이용권코드}.ics
파일 포맷 ICS (iCalendar) — iOS·Google·삼성 캘린더 공통 표준
동기화 주기 폰 설정에 따라 자동 갱신 (iOS: 기본 1시간, Google: 12시간~24시간)
보안 이용권 코드(`SM-XXX-XXX`)가 URL에 포함 → 코드 없으면 접근 불가
방향 단방향: 캐디Pro → 폰 (폰에서 캐디Pro로 역방향 반영은 불필요)

4 ICS 생성 코드 예시

src/app/api/calendar/[code]/route.ts 핵심 로직

// GET /api/calendar/SM-YK3-PZC.ics export async function GET(req: Request, { params }) { const code = params.code.replace('.ics', '').toUpperCase(); // 1. 이용권 확인 + tier 조회 const { data: lic } = await db .from('aone_pro_caddypro_licenses') .select('tier, is_active, expires_at') .eq('code', code) .maybeSingle(); if (!lic?.is_active) return new Response('Unauthorized', { status: 401 }); // 2. 일정 조회 let query = db.from('aone_pro_caddypro_schedules') .select('*').eq('license_code', code); // ★ 프리미엄: 전체 / 스탠다드: 근무 일정만 if (lic.tier !== 'premium') { query = query.eq('type', 'work'); } const { data: schedules } = await query; // 3. ICS 생성 const ics = buildICS(schedules, code); return new Response(ics, { headers: { 'Content-Type': 'text/calendar; charset=utf-8', 'Content-Disposition': `attachment; filename="caddy-${code}.ics"`, 'Cache-Control': 'no-cache', } }); }

src/lib/icsBuilder.ts — ICS 문자열 생성

function buildICS(schedules: Schedule[], code: string): string { const lines = [ 'BEGIN:VCALENDAR', 'VERSION:2.0', `PRODID:-//캐디 매니저 Pro//KR`, 'X-WR-CALNAME:캐디 매니저 Pro', 'X-WR-TIMEZONE:Asia/Seoul', 'CALSCALE:GREGORIAN', ]; for (const s of schedules) { const dateStr = s.date.replace(/-/g, ''); // 20260410 const summary = s.type === 'work' ? `🏌 ${s.shift}부 근무` : s.type === 'personal' ? `📌 ${s.title}` : '🌿 휴무'; lines.push( 'BEGIN:VEVENT', `UID:${s.id}@caddy-pink.vercel.app`, `DTSTART;VALUE=DATE:${dateStr}`, `SUMMARY:${summary}`, s.memo ? `DESCRIPTION:${s.memo}` : '', 'END:VEVENT' ); } lines.push('END:VCALENDAR'); return lines.filter(Boolean).join('\r\n'); }

6 스탠다드 → 프리미엄 충동 구매 시나리오

🎯 충동 구매를 일으키는 4단계 UX 흐름

1
스탠다드 사용자: 앱 홈에서 "📅 캘린더 구독" 버튼 노출 (잠금)

자물쇠 아이콘 + 회색 처리. "근무 일정을 폰 캘린더와 연동" 문구로 호기심 자극
→ 존재는 알지만 못 쓰는 상태 = 심리적 박탈감 유발

2
클릭 시 → 비교 팝업 등장

스탠다드(근무만) vs 프리미엄(전체) 차이를 시각적으로 보여줌
예: "개인 일정 12개가 아직 폰과 동기화되지 않았습니다."
→ 실제 데이터를 꺼내 개인화된 숫자로 찌름

3
프리미엄 전환 버튼 + 금액 명시

"월 ○○원 추가로 모든 일정을 폰 캘린더와 자동 동기화"
금액을 커피 1잔 수준으로 표현 → 결제 진입 장벽 최소화

4
전환 직후 → 바로 캘린더 구독 완료 화면

결제 완료 → 즉시 구독 URL 발급 → "지금 바로 폰 캘린더에 추가하세요"
→ 가치를 즉시 체감시켜 후회 없는 구매 경험 제공

추가 업셀 트리거 포인트

상황 노출 문구 (예시) 위치
개인 일정 등록 직후 "📅 이 일정, 폰 캘린더에도 자동으로 뜨게 하려면?" → 프리미엄 배너 일정 저장 완료 토스트 하단
오전 알림 수신 후 "폰 기본 캘린더에서도 확인하고 싶다면 프리미엄으로" (카카오톡 알림 하단) 카카오 알림톡 버튼 추가
이용권 갱신 시점 연장 페이지에서 "이번엔 프리미엄으로 바꿔보세요 +캘린더 동기화 포함" /subscribe 페이지
스탠다드 구독 URL 사용 중 ICS 내 Description에 "⭐ 개인 일정도 동기화: 프리미엄 업그레이드" 한 줄 삽입 폰 캘린더 일정 상세
