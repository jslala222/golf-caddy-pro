본사 ↔ 딜러 ↔ 고객 간 돈의 흐름과 각 단계별 영수증·세무 처리

🗺️ 전체 돈의 흐름 — 한눈에
═══════════════════════════════════════════════════════ 【 흐름 1 】 본사 → 딜러 (크레딧 판매) ─────────────────────────────────────────────────────── 딜러가 본사에 크레딧 구매 (포트원) 카드결제 → 카드사 자동 영수증 ✅ 계좌이체 → 포트원 현금영수증 ✅ (자동 or 자진발급) → 이 단계 영수증은 완전 자동 처리됨 【 흐름 2 】 딜러 → 고객 (코드 발급) ─────────────────────────────────────────────────────── 딜러가 크레딧 차감 → 고객에게 이용권 코드 전달 고객이 딜러에게 현금 or 개인계좌로 결제 → 포트원 거치지 않음 → 자동 영수증 없음 → 딜러 유형에 따라 처리 방식이 완전히 다름 【 흐름 3 】 본사 → 딜러 (수수료 정산) ─────────────────────────────────────────────────────── 딜러에게 수수료(마진) 지급 → 딜러 유형에 따라 처리 다름 ═══════════════════════════════════════════════════════
👥 딜러 유형 2가지 — 처리 방식 완전히 다름
🔵 안 A — 사업자 딜러
  • 개인사업자 or 법인 사업자 보유
  • 본인 명의로 세금계산서/현금영수증 발행 가능
  • 부가세 신고 의무 직접 부담
  • 본사와 세금계산서 교환으로 정산
🟢 안 B — 프리랜서 딜러 (주력)
  • 사업자등록증 없음
  • 고객에게 현금영수증 발행 불가
  • 본사가 수수료 지급 시 3.3% 원천징수
  • 연 1회 지급명세서 제출 (본사 의무)
💳 흐름 1 상세 — 본사가 딜러에게 크레딧 판매
딜러 (A or B)
→
본사 결제페이지 (포트원)
→
영수증 자동 처리 ✅
결제수단영수증 처리별도 작업
카드결제카드사 자동 발행없음
계좌이체 + 고객 번호 입력포트원 자동 발행없음
계좌이체 + 번호 미입력 + 10만원↑서버 자진발급 자동없음 (코드로 구현됨)
계좌이체 + 번호 미입력 + 10만원↓의무 없음없음
✅ 흐름 1은 완전 자동 — 본사가 추가로 할 일 없음 포트원이 모든 영수증 처리. 딜러 유형(A/B) 관계없이 동일하게 처리됨.

※ 포트원 거치지 않음 → 자동 처리 없음 → 딜러가 직접 처리해야 함

🔵 안 A 딜러 — 고객 영수증
  • ✅ 본인 사업자 명의로 발행 가능
  • 현금영수증: ARS 126 or 손택스 앱
  • 세금계산서: 홈택스 전자 발행
  • 우리 프로그램 현금영수증 탭 사용 ❌ (본사 명의로 나옴)
직접 발행 방법 ① ARS 126 → 2번 → 사업자번호 → 금액 → 고객번호 (30초)
② 손택스 앱 → 현금영수증 → 발급
🟢 안 B 딜러 — 고객 영수증
  • ❌ 사업자 없음 → 고객에게 발행 불가
  • 우리 프로그램 탭으로 발행하면?
  • → 본사 명의로 나감
  • → 본사가 그 돈 받지 않음 = 허위영수증 ⚠️
❌ 합법적 발행 방법 없음 고객이 영수증 원하면 → 본사 결제페이지로 유도
"현금 결제는 영수증 발행 불가" 고객에게 안내 필요
🧾 흐름 3 상세 — 본사가 딜러에게 수수료 정산
🔵 안 A 딜러 정산
  • 1
    딜러가 본사에 세금계산서 발행
    수수료(마진) 금액으로 역발행
  • 2
    본사가 수수료 입금
    원천징수 없음, 세금계산서 수취
  • 3
    본사 장부 매입비용 처리
    부가세 매입세액 공제 가능
🟢 안 B 딜러 정산
  • 1
    본사가 수수료에서 3.3% 차감
    소득세 3% + 지방소득세 0.3%
  • 2
    잔액 딜러 계좌 입금
    매월 정산 시 실수령액 지급
  • 3
    매월 10일 원천세 신고 (홈택스)
    소득 구분 코드 A03 (사업소득-인적용역)
  • 4
    다음해 3월 지급명세서 제출
    딜러별 인적사항 포함, 미제출 시 2% 가산세
📱 우리 프로그램 현금영수증 탭 — 실제 사용 가능 여부
상황 탭 사용 가능? 이유
안 A 딜러가 고객에게 현금 수금 ❌ 사용 불가 본사 명의로 발행되므로 적합하지 않음
안 B 딜러가 고객에게 현금 수금 ❌ 허위영수증 본사가 그 돈 받지 않음 → 세무 문제
딜러가 본사 계좌로 받은 돈 재정산 ⚠️ 구조적 불가 딜러-고객 간 거래는 본사와 무관
⚠️ 결론 — 현금영수증 탭은 현재 구조에서 사용처 없음 딜러가 고객에게 어떤 방식으로 받든 우리 탭으로 발행하는 건 적합하지 않습니다.
탭 기능보다는 딜러 유형별 안내 가이드로 대체하는 것이 현실적입니다.
🙋 고객이 영수증을 원할 때 — 딜러가 할 수 있는 것
🔵 안 A 딜러 고객
  • ARS 126으로 직접 현금영수증 발행 ✅
  • 홈택스로 세금계산서 발행 ✅
  • 카드단말기 보유 시 카드 결제 ✅
  • 모든 방법 사용 가능
🟢 안 B 딜러 고객
  • 현금 결제 → 영수증 발행 방법 없음
  • 해결책: 고객에게 본사 결제 페이지 유도
  • → caddy-pink.vercel.app/subscribe
  • → 포트원으로 결제 → 영수증 자동
  • 딜러는 본사에서 수수료로 정산받음
💡 핵심 원칙 고객이 영수증이 필요하면 → 항상 포트원(본사) 결제를 거쳐야 함
딜러가 중간에서 현금 수령 후 영수증을 발행할 수 있는 합법적 방법:
→ 안 A (사업자 딜러): 본인 명의로 직접 발행
→ 안 B (프리랜서): 없음 → 본사 결제 유도만 가능
📊 딜러 유형별 전체 처리 정리표
구분 🔵 안 A (사업자 딜러) 🟢 안 B (프리랜서 딜러)
크레딧 구매 영수증 자동 (포트원) 자동 (포트원)
고객 현금 수금 영수증 본인 발행 (ARS 126) 발행 불가
고객이 영수증 원할 때 직접 발행 본사 결제 유도
수수료 정산 방식 세금계산서 교환 3.3% 원천징수 후 지급
본사 세무 의무 세금계산서 수취 + 매입비용 원천세 신고 + 지급명세서
우리 현금영수증 탭 사용 불가 (본사 명의) 허위영수증 위험
딜러 진입 장벽 높음 (사업자 필요) 낮음
✅ 우리가 해야 할 것 — 액션 리스트
  • 1
    딜러 계약서 작성 (A/B 유형별)
    안 A: 세금계산서 교환 조항 | 안 B: 3.3% 원천징수 동의 + 주민번호 수취
  • 2
    딜러 등록 시 A/B 유형 구분 저장 (DB)
    관리자 페이지 딜러관리 탭에 사업자 여부 필드 추가
  • 3
    안 B 딜러에게 고객 안내 문구 제공
    "현금 결제 시 영수증 불가, 본사 결제 시 자동 발행" 안내카드
  • 4
    안 B 딜러 수수료 지급 시 3.3% 원천징수 실행
    매월 10일 홈택스 원천세 신고 (A03 코드)
  • 5
    현금영수증 탭 → 안내 가이드 탭으로 교체 (선택)
    실제 발행 기능 대신 유형별 안내 + ARS 126 링크로 대체 고려
  • 6
    세무사 1회 상담 (딜러 10명 이상 시)
    지급명세서 누락 가산세 2% 방지, 원천징수 신고 방법 확인
