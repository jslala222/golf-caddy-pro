1

가입 환영 SMS 자동 발송 연결 긴급

현재 POST /api/notify/welcome API는 만들어졌지만, 실제 이용권 발급 로직인 src/lib/licenseUtils.ts의 issueVoucher() 함수에서 호출이 안 됨.

📌 수정할 위치: licenseUtils.ts → issueVoucher() 내부, INSERT 완료 직후
📌 필요한 것: 사용자가 입력한 전화번호를 이용권 발급 폼에서 받아야 함

2

실기기 SMS 수신 테스트 긴급

설정 페이지에서 전화번호 입력 + 시각 선택 후 저장 → DB 반영 확인
Cron 수동 테스트: GET https://caddy-pink.vercel.app/api/cron/alarm?hour=6 (Authorization 헤더 필요: Bearer {CRON_SECRET})

📌 아직 실제로 SMS가 발송된 적 없음 → 반드시 테스트 필요

3

Vercel Cron 플랜 이슈 해결 보통

Vercel Hobby 플랜은 Cron Job 하루 1개만 가능. 현재 vercel.json에 5개 등록 → 1개만 실행될 수 있음.

옵션 ①: Vercel Pro 업그레이드 ($20/월)
옵션 ②: 단일 Cron으로 통합 (15분마다 실행 → 현재 시각 확인)
옵션 ③: 기본값 6시 1개만 운영 (단순화)

4

개인 약속 사전 알림 낮음

캐디가 골프 약속 30분/1시간 전에 SMS 알림 받는 기능.
현재는 "아침 일정 요약"만 가능. 개별 약속 N분 전 알림은 Cron으로 구현 시 1분 단위 실행이 필요 → 별도 방식(예약 시 SMS 예약 발송) 검토 필요.
