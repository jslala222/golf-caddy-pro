관리자 / 딜러 운영 가이드

  • 연장 처리 시 전화번호 확인
    딜러 대시보드 연장 버튼 클릭 시 DB에 phone이 있으면 연장완료 SMS(5번) 자동 발송
  • 사용자가 SMS 못 받는다고 할 때
    → 설정 페이지에서 전화번호가 저장됐는지 확인
    → Vercel 함수 로그 확인: https://vercel.com/jslala222/caddy-pro-enterprise/logs
  • Cron 작동 확인 (관리자)
    Vercel 대시보드 → Functions → /api/cron/alarm, /api/cron/expire-notify 로그 확인
    ※ Hobby 플랜은 Cron이 1개만 실행 — 5시 브리핑만 동작, 나머지는 배포 후 수동 테스트

알림톡 템플릿 승인 후 할 일

✅ 현재 상태 (SMS로 전부 동작 중)

  • 5개 템플릿 모두 일반 LMS(SMS)로 구현 완료 · 배포됨
  • 알리고 알림톡 템플릿 5종 심사 접수됨 (영업일 3~5일 소요)

⏳ 알림톡 승인 후 교체 작업 (코드 변경 최소)

  • 알리고 → 신청/인증 탭 → 각 템플릿 코드(ID) 수집
  • src/lib/aligo.ts에 sendAlimtalk() 함수 추가
  • /api/notify/welcome, /api/notify/extend, /api/cron/alarm, /api/cron/expire-notify 에서
    sendSMS() → sendAlimtalk() 교체 (파일 4개, 각 1줄 수정)
  • 실패 시 sendSMS() fallback 자동 처리
테스트 방법
  • 1번 테스트 (가입 환영)
    관리자 페이지 → 이용권 발급 → 전화번호 입력 후 발급
    → 즉시 SMS 수신 확인
  • 2·3번 테스트 (오늘 일정 브리핑)
    설정에서 전화번호 + 알림 시각 저장
    → Vercel 대시보드에서 Cron 수동 실행: GET /api/cron/alarm?hour=6
    → 또는 해당 시각까지 대기
  • 4번 테스트 (만료 알림)
    Vercel 대시보드에서 수동 실행: GET /api/cron/expire-notify
    → expires_at이 7일 이내인 이용권 + phone 등록된 계정 필요
  • 5번 테스트 (연장 완료)
    딜러 대시보드 → 기존 이용권 연장 처리
    → 즉시 SMS 수신 확인 (해당 이용권에 phone 저장 필수)
