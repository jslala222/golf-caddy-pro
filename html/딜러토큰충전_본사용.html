⚙️ 본사 운영 프로세스 (Step by Step)
1
딜러 입금 확인
딜러가 계좌이체 후 카카오톡/문자로 입금 내역 전송. 본사 계좌 확인.
2
충전량 계산
입금액 ÷ 단가 = 크레딧 수. 보너스 크레딧 해당 여부 확인 후 합산.
3
관리자 패널에서 크레딧 추가
관리자 대시보드 → 딜러 계정 선택 → 크레딧 충전. Supabase DB 직접 업데이트.
4
딜러 확인 전송
카카오톡으로 "N크레딧 충전 완료, 잔액 OO개" 메시지 발송. 영수증 역할.
5
딜러 이용권 발급 시 자동 차감
딜러가 고객에게 이용권 발급 → 크레딧 1개 자동 차감. 잔액 부족 시 발급 차단.
⚠️ 주의: 크레딧 충전 전 입금 확인 필수. 선충전 원칙 (미입금 선발급 금지). 딜러 연체 발생 시 계정 즉시 잠금.
🔲 미결정 사항 (추후 논의)
  • ⬜ 카드 결제 PG사 연동 시점 (토스페이먼츠 vs 아임포트)
  • ⬜ 딜러 등급제 도입 여부 (실버/골드/플래티넘 구분)
  • ⬜ 관리자 패널 자동화 — 딜러가 직접 충전 요청 전송 기능
  • ⬜ 세금계산서 발행 필요 딜러 대응 방안
  • ⬜ 크레딧 만료 1년 → 6개월 단축 여부 (수익성 고려)
  • ⬜ 딜러 모집 채널 (이메일 / 오픈채팅 / 크몽)
