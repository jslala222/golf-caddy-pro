장점 / 단점

  • ✅ 딜러 수익이 명확하고 즉각적 체감 → 동기부여 UP
  • ✅ 수수료 계산 자동화 불필요 (선충전이므로 이미 정산 완료)
  • ✅ 딜러가 가격 자유 설정 (50,000원, 60,000원 등)
  • ✅ 갱신 문제 없음 (딜러 토큰 소모하면 그만)
  • ❌ 딜러가 선 투자 필요 (토큰 미리 구매해야)
  • ❌ 딜러 토큰 관리 화면 추가 개발 필요
  • ❌ 딜러가 충전하지 않으면 발급 불가 (재고 개념)
  • ❌ 본사가 딜러 충전금 받는 결제 프로세스 필요

05
수수료 배분 규칙 — 갱신·재계약·휴면 케이스
📌
텍스트 파일에서 발견된 구체적 질문:
"딜러가 판매시 6개월 50,000원 판매했음. 7일전 딜러와 다시 6개월 계약 진행했을 경우 수익 분배는?"
"딜러가 판매시 6개월 50,000원 판매했음. 몇달 쉬었다 다시 판매했음. 판매코드는?"
📋 케이스 1 — 만료 7일 전 갱신 (딜러 통해 재계약)
상황: 딜러 A가 고객에게 6개월권 판매 → 만료 7일 전에 딜러 A를 통해 재계약

추천 규칙: 딜러 수수료 100% 지급.
이유: 딜러가 직접 관리하여 재계약으로 이어진 것. 딜러 영업 활동의 결과.
📋 케이스 2 — 만료 7일 전 갱신 (고객이 직접 온라인 결제)
상황: 딜러 A가 고객에게 소개 → 고객이 직접 /subscribe 접속해서 카드 결제

추천 규칙 (안 A 기준): 최초 이용권의 ref= 값 추적해서 수수료 지급.
구현 방법: 고객 phone 번호로 기존 ref 조회 후 동일 딜러 수수료 적용.
추천 규칙 (안 B 기준): 해당 없음. 딜러 토큰 소모 없으면 수수료 없음.
📋 케이스 3 — 몇 달 쉬었다 재사용 (딜러 통해 재계약)
상황: 딜러 A 소개 → 3개월 사용 → 2개월 휴면 → 딜러 A 통해 재계약

추천 규칙: 딜러 수수료 100% 지급. (딜러가 재접촉·영업한 결과)
✅ 확정: 기존 이용권 코드 기간 연장 (코드 변경 없음, expires_at만 갱신).
이유: R2 백업 경로가 {code}/latest.json이므로 코드 변경 시 백업 데이터 유실.
📋 케이스 4 — 몇 달 쉬었다 재사용 (고객이 직접 온라인 갱신)
상황: 딜러 A 소개 → 3개월 사용 → 2개월 휴면 → 고객 혼자 온라인 결제

추천 규칙: 수수료 없음 OR 초회 딜러에게 10% 지급 (선택).
권장: 수수료 없음. 딜러 영업 없이 고객 자발적 갱신이므로 본사 full 수익.
📋 케이스 5 — 딜러 A 소개 → 이후 딜러 B 통해 갱신
상황: 딜러 A가 최초 소개했으나, 고객이 딜러 B를 통해 갱신 요청

추천 규칙: 갱신 시점의 딜러(딜러 B)에게 수수료 지급.
이유: 실제로 재판매한 딜러가 B이므로 B가 영업의 주체. 단순 명확성.
📋 케이스 6 — 딜러가 한동안 영업을 안 했다가 재개 (판매코드)
상황: 딜러 A가 몇 달 쉬었다가 다시 판매 시작

추천 규칙 (안 B): 기존 딜러 토큰(dealer URL) 그대로 유지. 크레딧 재충전만 하면 됨.
추천 규칙 (안 A): 딜러 is_active 상태 관리. 관리자가 재활성화 처리.

📐 수수료 배분 규칙 정리표

케이스 딜러 개입 수수료 이용권 코드
만료 임박 + 딜러 통해 갱신 O 100% 지급 기간 연장
만료 임박 + 고객 직접 온라인 갱신 X 초회 딜러 20% (또는 0%) 기간 연장
휴면 후 딜러 통해 재계약 O 100% 지급 기간 연장

다른 딜러 통해 갱신 타딜러 갱신 딜러 100% 기간 연장
딜러 재가동 (휴면 딜러 재시작) — 관리자 재활성화 기존 URL 유지

왜 하이브리드인가?

1. 딜러 상황별 유연성
조장 10명 묶음 판매 같은 현금 대량 거래는 딜러가 직접 즉시 발급(안 B 방식).
처음에 충전 자금이 없는 신규 딜러나 고객이 직접 카드로 내겠다는 경우는 결제 링크(안 A 방식).

2. 젊은 세대 직접 결제 선호
"요즘 젊은 세대는 직접 결제에 1/N 방식을 좋아하기도 함" → 결제 링크가 필수.
딜러가 링크를 생성해서 카카오로 보내면 고객이 각자 결제 — 딜러는 현금 관리 부담 제로.

3. 갱신 = 기간 연장 (코드 유지)
갱신 시 이용권 코드를 신규 발급하지 않고 기존 코드의 expires_at만 연장.
이유: R2 백업 경로가 {code}/latest.json이므로 코드 변경 시 백업 유실됨.
딜러 대시보드에서 전화번호 검색 → 기존 코드 조회 → 기간 연장 버튼으로 구현.

4. 딜러 대시보드 구현 상태
[신규 발급] / [기간 연장] 모드 토글 — 딜러가 탭 전환으로 편리하게 사용.
기간 연장 완료 화면에서도 기존 코드 그대로 표시, 새 만료일 안내.
📋 구현 순서 (우선순위)
① dealers 테이블에 credits_1month / credits_6month / credits_year 컬럼 추가
② dealer_credit_history 테이블 신규 생성 (충전/사용 이력)
③ 관리자 페이지에 딜러 토큰 충전 기능 추가 (관리자가 충전해줌)
④ 딜러 대시보드에 크레딧 잔여량 표시 + 즉시 발급 버튼
⑤ 이용권 발급 시 해당 딜러 크레딧 자동 차감
💰 최종 확정 가격표 (추천)
구분 온라인 공시가 딜러 도매가 딜러 권장 판매가
1개월권 9,900원 7,000원 9,000 ~ 11,000원
6개월권 55,000원 40,000원 48,000 ~ 58,000원

📜 확정된 운영 규칙
✅ 딜러 즉시 발급 — 신규 고객에게 코드 즉시 생성 (이름+전화번호 입력)
✅ 갱신 = 기간 연장 — 전화번호 검색 → 기존 코드 기간만 연장 (코드 불변)
✅ 결제 링크 — 고객이 직접 카드/이체로 결제 시 자동 코드 발급 (안 A 방식)
✅ 딜러 대시보드 — [신규 발급] / [기간 연장] 탭 토글로 분리

✅
최종 확정 결론
안 A + 안 B 하이브리드 채택 — 구현 완료.
