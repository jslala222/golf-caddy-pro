C안 실행 문서

캘린더 자동 동기화 구현계획

목표: 사용자는 최초 1회 연결만 하고, 이후 일정 반영은 거의 무조작으로 유지

작성일: 2026-04-09 · 대상: Caddy Manager Pro (갤럭시/아이폰 공통)

1) 구현 범위

핵심 기능

  • 설정 화면에서 캘린더 구독 URL 즉시 복사 + 등록 안내
  • ICS API의 안정성 강화(이용권 상태, 만료, 티어 분기, 응답 캐시)
  • 프리미엄 전환 시 동기화 가치를 한 화면에서 명확히 제시

확장 기능 (C안 방향)

  • 모바일 브리지 앱(또는 래퍼)로 기기 캘린더 자동 등록 UX 제공
  • 최초 권한 허용 이후 배경 동기화 스케줄 적용
  • 실패 시 재시도/오류 알림 로직 탑재
1주 MVP
2주 안정화
3주 확장
주의: 안드로이드 제조사별 정책 차이로 "완전 무설정"은 네이티브 브리지 도입이 필수입니다.

2) 단계별 일정

WEEK 1

웹 MVP: 기존 ICS 흐름 고도화, 설정 페이지 온보딩 문구, 갤럭시 가이드 통일.

WEEK 2

실기기 검증: 삼성/구글 계정별 동기화 지연 시간 측정, 이탈 구간 개선.

WEEK 3

C안 PoC: 모바일 브리지 앱에서 URL 자동등록 + 권한 획득 플로우 구현.

WEEK 4

상용 준비: 프리미엄 업셀 문구 AB 테스트, 장애/로그 모니터링 체계 반영.

성과 기준: 설정 완료율 70%+, 프리미엄 전환율 +15%, 캘린더 문의량 -30%.

3) 진행 미리보기 이미지

이미지 설명: 사용자 흐름(설정 진입 → URL 등록 → 자동동기화)과 개발 로드맵(웹 MVP → 브리지 확장)을 한 장으로 요약.
