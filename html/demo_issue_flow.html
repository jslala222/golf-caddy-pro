❌ 현재 방식 (문제)

🔴딜러가 코드를 화면에서 확인 후 직접 문자/카톡으로 수동 발송
🔴딜러 실수로 코드 전달 누락 가능
🔴고객이 코드를 받았는지 확인 불가

✅ 개선 방식 (권장)

🟢발급 버튼 클릭 즉시 자동으로 카카오/문자 발송
🟢고객이 카카오 채널로 이용권 코드 즉시 수신
🟢링크 클릭 한 번으로 앱 활성화 가능
🟢발송 이력 DB에 자동 기록

📌 시나리오 A — 딜러 무결제 발급

💡딜러가 현장에서 수수료 받고 이용권 발급
💡발급 즉시 이용권 코드를 카카오 알림톡으로 발송
💡구현: 카카오 비즈메시지 API or 알림톡 서비스
💡대안: 네이버 클라우드 SENS (SMS/LMS)

📌 시나리오 B — 고객 직접 결제 유도

💡딜러가 고객 정보 입력 → 개인화 결제 링크 생성
💡링크를 카카오로 발송 → 고객이 직접 결제
💡결제 성공 시 자동으로 코드 발급 + 재발송
💡딜러 수수료는 affiliate_code로 추적
